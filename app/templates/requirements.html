Требования

  1. У вас есть две тестовых учетных записи:
    Логин admin , пароль admin
    Логин user, пароль user
    Иногда записывают в формате логин / пароль: admin / admin и user / user
    При успешном логине пользователем user должна открыться страница /to_do_list
    При успешном логине пользователем admin должна открыться страница /admin
  2. Ссылка Sign up! Ведет на страницу регистрации
  3. В поле Password введенные символы должны быть замаскированы точками
  4. Клик ЛКМ на пиктограмме глаза в правой части поля Password переключает показ или маскирование символов в поле Password
  5. Поля Login и Password обязательны для заполнения
  6. При наведении курсора мыши на иконку “кружок с вопросительным знаком” в левом нижнем углу должна появляться подсказка о тестовых учетных записях администратора и пользователя
  7. В случае, если введены некорректные учётные данные, под кнопкой должно появиться сообщение об ошибке “Invalid login or password”, цвет шрифта красный
